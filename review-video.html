Speed Monitor 1.1.0 (version 2)

Foreground service demonstration for com.jonkryl.speedmonitor.

  1. The user taps Start monitoring in the visible application.
  2. An ongoing notification displays the current device network traffic rate while the monitor is active.
  3. The user taps Stop in that notification. The monitor and notification stop; the app shows the stopped state.

This is a screen recording of the signed release APK generated from version 2 of the Play App Bundle, running on an Android 16 emulator. The foreground service passively samples local Android TrafficStats counters. It does not generate a speed-test download or upload. Reboot resume is a separate opt-in setting; Stop persists the stopped state.

Демонстрация фонового мониторинга

В видео показана подписанная версия 1.1.0: запуск пользователем, видимое уведомление с текущей скоростью трафика и остановка через кнопку в уведомлении. После остановки приложение показывает остановленное состояние.
